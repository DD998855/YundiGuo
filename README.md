# Yundi Guo — Portfolio

Personal portfolio of **Yundi Guo (郭云笛)** — an AI Product & Interaction Designer exploring how complex systems, information, and emerging technology can become clear, human-centered experiences.

## Selected Work

- **FLOW** — AI product prototype for turning work buried in WeChat conversations into visible, actionable workflows.
- **DILAB** — brand identity, company website, AI research communication, editorial visuals, and digital design.
- **AED Training Module** — interactive learning experience that turns emergency procedures into guided practice.
- **Cloud Interactive Installation** — spatial interaction concept where human movement becomes input.
- **Emotional Creature** — interaction exploration that makes emotional states visible and responsive.
- **Daily Grind Dashboard** — dashboard and information-design study.
- Additional web, typography, and experimental interaction projects.

## Focus

AI product experience · interaction design · UX · prototyping · information architecture · visual systems · web design

## Built With

React · Next.js · TypeScript · CSS · JavaScript
